## 🌐 Free Online Deployment Options

### Option 1: Netlify (Drag & Drop)
1. Go to [app.netlify.com/drop](https://app.netlify.com/drop).
2. Drag and drop the `e:\TyreSales` folder.
3. Your website is instantly live with free HTTPS and custom domain support.

### Option 2: Vercel
1. Install Vercel CLI: `npm i -g vercel`
2. Run `vercel` inside `e:\TyreSales`.

### Option 3: GitHub Pages
1. Push this folder to a GitHub repository.
2. Go to **Settings > Pages** and set source to `main` branch.
